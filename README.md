# Эмаль — сайт стоматологии с 3D-зубом

Концепт сайта стоматологической клиники. Главный элемент — 3D-модель зуба на импланте, которая проходит через три сцены.

## Что есть на сайте

- **3D-зуб из трёх деталей**: керамическая коронка, золотистый абатмент и титановый имплант с резьбой. Модель построена кодом на Three.js, без готовых 3D-файлов
- **Разборка при прокрутке**: зуб разделяется на детали, рядом по очереди раскрывается описание каждой
- **Отбеливание**: ползунок меняет оттенок эмали по шкале VITA от A4 до BL1
- Клиника, прайс таблицей, врачи, отзывы, вопросы и ответы
- Запись на приём с выбором услуги и времени
- Адаптив под телефон

## Технологии

Чистые HTML, CSS и JavaScript. Three.js лежит в проекте локально, на странице включена Content Security Policy.
